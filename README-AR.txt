SERVERNOVA — نسخة البداية
=========================

محتويات الحزمة:
- index.html : صفحات وواجهة الموقع.
- style.css  : التصميم المتجاوب.
- app.js     : التنقل والبحث التجريبي.
- assets/    : مكان الصور والملفات الإضافية.

طريقة التشغيل:
1) فك ضغط SERVERNOVA.zip.
2) افتح مجلد SERVERNOVA.
3) اضغط مرتين على index.html لفتحه في المتصفح.

مهم:
هذه نسخة واجهة أولية (Front-end prototype)، وليست منصة متصلة بعد.
بيانات السيرفرات الظاهرة أمثلة تجريبية وليست بيانات حقيقية أو مباشرة.
البحث يعمل على الأمثلة الموجودة فقط.
الشات، الحسابات، Steam/Google login، إنشاء السيرفرات، مراقبة السيرفرات،
قاعدة البيانات، لوحة الإدارة، التبليغ، الإشعارات، والألعاب الجماعية
تحتاج Backend وقاعدة بيانات وخدمات وربطاً حقيقياً قبل إطلاق الموقع.

لا تضع كلمات مرور أو مفاتيح API داخل ملفات الواجهة.
