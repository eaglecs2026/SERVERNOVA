# SERVERNOVA — خريطة الشاشات والواجهة

## الشريط الرئيسي
- Home
- Server Browser
- Games
- Community
- My Profile
- Notifications
- Settings

## Server Details
Header: server name, status, verification labels.
Main panel: game, map, country, players, ping, last checked.
Actions: Copy IP:Port, Favorite, Report.
Tabs: Overview, Players (if public), History, Reviews.

## My Profile
Cover + avatar + display name + username + bio.
Tabs: Overview, Posts, Favorite Servers, Friends.
Privacy controls: Public / Friends / Only me.

## Community
Internal tabs: Feed, Friends, Messages, Communities, Search.
Community view: member list, roles, text channels, invite link, moderation tools.
Direct message view: conversation list + message panel + report/block controls.

## Mini Games
Game cards: Snake, Chess, Ludo, Puzzle, 2D Racing.
Each card opens a lightweight game screen with Start, Restart, Instructions.
Start with Snake as the first playable implementation.

## Account Center
Login / Register / Verify Email / Reset Password.
Linked Accounts: SERVERNOVA account, Google, Steam.
For each external provider: Connect, Connected identity, Unlink.
Never ask for a Google or Steam password directly.
